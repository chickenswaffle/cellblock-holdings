# Click-to-place doors

While reviewing a new unit or a wall plan, click directly on the wall where the doorway should go. You can click proposed walls or an installed shared wall. There is no separate connection setup step. Build → Structure → Door uses the same placement path for installed walls.

- Hover shows a green opening when the local geometry and furniture clearance permit it, or red when that location is blocked. Final route and quote checks run on the click and approval.
- Each click updates the current project quote. It does not charge money, start construction or make the opening usable.
- Existing doors and earlier clicks are preserved, including openings on curved walls. Multiple openings use separately editable wall pieces along the original shape.
- **Undo last door** or **Command/Ctrl+Z** restores the previous plan. Discard cancels the full unapproved project. Saving preserves the current draft; undo history is session-only and clears when loading or changing companies.
- Drag the view while reviewing, use arrows/WASD, and pinch or scroll to zoom. Review and approval stay visible while choosing doors.

The full doorway and jambs must border a continuous shared boundary. Corners, existing openings and obstructing furnishings reject the click while preserving the draft. A draft which already has route errors can receive more doors; approval stays disabled until the full quote is valid.
